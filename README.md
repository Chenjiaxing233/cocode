# React Monaco Code Editor

一个运行在浏览器中的轻量级代码编辑器，支持本地文件编辑、工作区搜索和多人实时协同。

在线体验：<https://chenjiaxing233.github.io/jx-web-code/>

> 请使用 Chrome 或 Edge。首次打开编辑器需要联网加载编辑器资源。

## 功能

- 打开本地文件或文件夹，浏览文件树
- 同时编辑多个文件
- 创建、删除和刷新文件及文件夹
- 语法高亮、文件图标和亮色/暗色主题
- 编辑内容自动保存到本地磁盘
- 检测外部文件修改并重新加载
- 关闭文件前提示未保存内容，并支持恢复最近关闭的文件
- 工作区搜索与替换
- 支持大小写、全词和正则表达式匹配
- 无需登录即可创建协同房间
- 实时同步文件内容、在线成员、光标和选区
- 支持将协作者设为可编辑或只读

## 本地运行

环境要求：Node.js 18 及以上、pnpm。

```bash
pnpm install
pnpm dev
```

然后打开 <http://localhost:5173>，点击“Open File”或“Open Folder”开始使用。

## 协同编辑

1. 点击顶部“共享协同”，选择协作者权限。
2. 复制生成的链接并发送给协作者。
3. 协作者打开链接后会自动加入房间。
4. 已打开的文件会共享给房间，协作者收到后会在新的标签页中打开。
5. 结束协同后点击“退出协同”。

协同链接包含加入房间所需的信息，请只发送给需要参与协作的人。

## 浏览器要求

Chrome 和 Edge 支持完整的本地文件编辑功能。Firefox 和 Safari 不支持本项目所需的本地文件访问能力。
